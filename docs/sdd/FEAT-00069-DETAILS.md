# Build Plan
1. Extractor (external repo `C:\git\bcnesa-extract-2`),
   `src/actas-pdf/convert_pdf_to_json.py` `parse_match`:
   - Determine whether the ABC team is home (`abc_is_home`): the line after
     `Jocs` holds games won as home/away, so compare it with the ABC/XYZ
     games tally; for ties, compare the normalised common prefix of the
     (possibly truncated) header names with each alignment-line name. If still
     undecidable, keep ABC as home and log a warning.
   - Write `equipos` by real side; when ABC is away, swap `alineaciones`,
     `dobles` and every `partidos[]` entry (`local`/`visitante`, `sets`,
     `resultado_juegos`, `ganador`) via `swap_sides`, keep `cruce` as written,
     recompute `marcador_acumulado`, and set `abc_es_local` accordingly.
   - `resultado_final.marcador_partidos` = games won (home/away),
     `marcador_juegos` = set totals from `Jocs` re-oriented to home/away,
     `ganador` = team with more games (null on a tie).
2. Extractor tests (`tests/test_convert_pdf_to_json.py`, `OrientationTests`):
   ABC away (real Horts–Ripollet page text), ABC home with separate games/sets
   scores, tie decided by truncated header prefix, undecidable orientation
   warns and keeps ABC home, re-oriented output matches the JSON schema.
3. Importer (this repo): BCNESA processors, `BcnesaMatchdaySplitter` and
   `BcnesaClubIndex` already read `equipos`, lineups and game participants by
   side and derive scores from each game's winner, so no production change is
   needed. Add `BcnesaImportProcessorsTest.storesLineupsGamesAndScoreOnTheRealSidesWhenTheXyzTeamIsHome`
   with fixture `src/test/resources/actas/acta_bcnesa_xyz_home.json`
   (generated by the fixed extractor from `2020-2021/Preferent/G1/1a Fase/acta_10.pdf`, page 2).
4. Data: regenerate BCNESA JSON (`--force` per season) and re-import BCNESA
   (requires user go-ahead; affects shared local data).

# Implementation Guidelines

- Orient at the source (extractor), matching the RFETM convention: lineups,
  doubles and games by real side, `abc_es_local` describing which letters the
  home team used, `cruce` unchanged.
- Stale BCNESA JSON carries no header or games line, so the importer cannot
  re-orient it; the fix only applies after regenerating the JSON.
- Do not change the importer's per-fixture score derivation, which already
  ignores `resultado_final`.

# Notes

- Root cause: the extractor took `equipos.local`/`visitante` from the
  `ABC <team> XYZ <team>` alignment line and hardcoded `abc_es_local: True`,
  so the ABC team was always stored as home. Players stayed with their own
  team, but home/away (and every home/away stat) was wrong whenever the ABC
  team was the away team. `marcador_partidos` also held the `Jocs` set totals
  (ABC/XYZ order) instead of games won, and `ganador` followed sets.
- Sample of 60 PDFs (263 pages): ABC home 130, ABC away 118, 15 headers not
  matched by exact name (truncated or suffixed names); `Jocs` equals ABC/XYZ
  set totals on all 248 checked pages and the following line equals games won
  in home/away order on all 248.
- Validation:
  - `python -m unittest tests.test_convert_pdf_to_json`: 8 passed (3 existing,
    5 new orientation tests).
  - The fixture generated from the real Horts–Ripollet page validates against
    the schema: `equipos` HORTS (home) / RIPOLLET, `abc_es_local` false, X/Y/Z
    under `local`, games 4-2, sets 14-6, final running score 4-2.
  - `BcnesaImportProcessorsTest.storesLineupsGamesAndScoreOnTheRealSidesWhenTheXyzTeamIsHome`
    passes. The class's other 3 failures (`expected N clubs/players but was
    0`) predate this work, as recorded in FEAT-00068.
- Full scan of all 3,689 BCNESA PDFs (16,387 pages, 5 unreadable): the games
  line decides 16,213 pages (ABC home 8,075, ABC away 8,138); the remaining
  174 are ties. Header-prefix matching decides all 16,387 pages (0
  ambiguous) and never disagrees with the games line, so orientation is
  determined for every page and the undecidable fallback is not hit.
- Pending: JSON regeneration with `--force` per season and BCNESA re-import.
